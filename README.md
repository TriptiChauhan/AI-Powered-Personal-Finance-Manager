# 💰 AI-Powered Personal Finance Manager

An **AI-powered Personal Finance Manager** that helps users track their income and expenses, analyze spending habits, and receive personalized financial recommendations using Artificial Intelligence.

The application provides an intuitive dashboard, detailed transaction management, and an AI Financial Planner to help users make smarter financial decisions.

---

# 📌 Project Overview

Managing personal finances can be difficult, especially when users have multiple income sources and daily expenses.

This project solves that problem by providing a centralized platform where users can:

- Track income and expenses
- Categorize transactions
- View financial analytics
- Monitor spending habits
- Receive AI-generated financial insights
- Plan monthly budgets intelligently

Unlike a traditional expense tracker, this application integrates **Google Gemini AI** to provide personalized financial planning and recommendations.

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/your-username/AI-Personal-Finance-Manager.git
```

---

## Navigate to Project

```bash
cd AI-Personal-Finance-Manager
```

---

## Install Frontend Dependencies

```bash
cd frontend
npm install
```

---

## Install Backend Dependencies

```bash
cd ../backend
npm install
```

---


# ▶️ Run the Backend

```bash
cd backend

npm run dev
```

---

# ▶️ Run the Frontend

```bash
cd frontend

npm run dev
```
